---
description: Connect to someone else's shared memory, or install and update your own
---

Use the `setup-memory` skill bundled with this plugin. First ask whether the user only wants to ask someone else's memory, or wants their own memory too. For the first, open the setup screen and let them enter the shared-bridge values there. For the second, detect the environment, offer the bundled local Docker server when Honcho is not already reachable, ask which detected agents to configure, show the generated plan, and apply it only after the user confirms.
